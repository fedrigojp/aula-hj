# Meu Projeto

Este projeto é uma página inicial simples em HTML, criada para apresentar uma saudação e uma mensagem de boas-vindas.

## O que foi feito

- Estrutura básica de uma página em HTML5
- Título da página: "Olá, Fatec"
- Conteúdo com mensagem de apresentação para a Fatec Santana de Parnaíba
- Projeto simples, sem dependências externas

## Descrição do projeto

A página principal está no arquivo `index.html` e foi desenvolvida como um exemplo de projeto versionado com Git e GitHub. Ela contém uma mensagem inicial e serve como base para futuras melhorias e novas funcionalidades.

## Como visualizar

1. Abra o arquivo `index.html` em qualquer navegador.
2. Se preferir, você também pode rodar um servidor local na pasta do projeto, por exemplo:

```bash
python -m http.server
```

Depois, acesse no navegador a URL indicada no terminal.

## Estrutura do projeto

- `index.html` — página principal do projeto
- `README.md` — documentação do projeto

## Observações

Este é um projeto inicial e pode ser expandido com estilos, imagens, mais seções e interatividade no futuro.
